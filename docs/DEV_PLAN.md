## 风险-任务对照

| 风险 | 关联Sprint | 缓解措施 |
|------|-----------|----------|
| LLM推理成本失控 | S1-S2 | Mock模式优先，国产模型降本 |
| 前端实时性能瓶颈 | S3 | WebSocket→轮询降级策略 |
| 冷启动品味模型无效 | S5 | 社区风格模板兜底 |
| 降临模式破坏NPC一致性 | S6 | 角色一致性守护先行开发 |
| 内容安全风险 | S6 | 敏感词过滤+人机协同审核 |
